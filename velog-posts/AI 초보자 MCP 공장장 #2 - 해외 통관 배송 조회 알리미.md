<h2 id="🎮-prologue--알리-강점기-내-택배-도대체-어디-짱박혀-있어">🎮 Prologue : 알리 강점기, &quot;내 택배 도대체 어디 짱박혀 있어?&quot;</h2>
<p>요즘 알리익스프레스, 테무 직구 메타다. 
결제는 1초컷인데, 배송은 심해를 유영하다가 세관이라는 거대한 레이드 보스 앞에서 하염없이 대기열을 탄다.
매번 관세청 유니패스(UNI-PASS) 웹사이트에 들어가서 12자리 HBL 번호를 손가락 관절 깎아가며 치고 있는 내 모습이 너무 한심했다.</p>
<p>&quot;아니 갓공지능 시대에 내가 왜 노가다 파밍을 하고 있어야 해?&quot;</p>
<p>지난번 '환율 계산기' 에셋을 성공적으로 빌드하며 자신감이 붙은 나는 다시 한 번 듬직한 AI 듀오 <strong>Antigravity</strong>를 호출했다.
&quot;Antigravity야, 이번 마일스톤은 관세청 API 연동 메인 퀘스트다. 알리 운송장 던지면 세관 통과 렌더링되게 깎아보자.&quot;</p>
<hr />
<h2 id="⚔️-scene-1--공공데이터포털의-함정-튜토리얼-퀘스트">⚔️ Scene 1 : 공공데이터포털의 함정 (튜토리얼 퀘스트)</h2>
<p>데이터 소스가 필요하니 관세청 OpenAPI 문서를 뒤졌다. 
첫 번째 함정 카드 발동! 인터넷에 굴러다니는 구닥다리 레퍼런스들은 공공데이터포털(data.go.kr)에서 키를 받으라고 핑을 찍어줬는데, 막상 가보니 화물통관진행정보는 유니패스 공식 웹사이트의 은밀한 '사이트맵 - 서비스관리' 구석탱이에서 직접 토큰을 발급받는 시스템으로 마이그레이션 된 지 오래였다.
리드미(README)에 이 뉴비 절단기 같은 설치법을 친절하게 스텝 바이 스텝으로 매뉴얼화 해두는 센스를 발휘했다.</p>
<p>게다가 응답 포맷이 <strong>순도 100% 퓨어 XML</strong>이다. 
&quot;요즘 씬에 JSON 형님이 아니라 XML 할아버지가 웬 말이냐!&quot; 
눈물을 머금고 <code>xml2js</code> 파서 패키지를 프로젝트 하이어라키에 인젝트했다.</p>
<hr />
<h2 id="💀-scene-2--시공의-폭풍-알리-익스프레스-연도-버그">💀 Scene 2 : 시공의 폭풍 (알리 익스프레스 연도 버그)</h2>
<p>서버 코어 로직을 다 짜고 Claude 클라이언트에 운송장 번호를 날렸다.
&quot;야, 998000341213 통관 현황 뽑아와!&quot;
결과: <strong>[0건] &quot;통관 진행 정보가 없습니다.&quot;</strong></p>
<p>어라? 나 분명 알리 앱에서 '세관 도착' 알림 받았는데? 브라우저로 유니패스 들어가서 쳐보니까 '반출완료'라고 잘만 뜨는데 내 코드만 멍청이가 되었다. 
디버깅 툴을 켜고 콘솔 로그를 파헤친 끝에 알아낸 충격적인 진실.</p>
<p>알리익스프레스 화물은 <strong>작년(2025년) 말에 발송되어서 올해(2026년) 세관에 입항</strong>장비를 드랍하는 경우가 허다하다. 유니패스 API는 융통성 제로의 철권 통치 중이라, <code>blYy</code>(발행 연도) 파라미터를 정확하게 안 꽂아주면 404를 때려버린다. 현재 연도 기준인 2026년으로 쿼리를 날렸는데, 세관 DB 형님들은 2025년 기록북을 들여다보고 계셨던 것.</p>
<p><strong>[핫픽스]</strong> 즉시 코루틴 자동 재시도 로직을 구현했다.
&quot;요청한 연도(2026)에서 <code>tCnt === '0'</code> 이 뜨면? 당황하지 말고 Time.deltaTime 깎듯 연도를 -1 해서 2025년으로 재귀 호출한다!&quot;
결과는 대성공. 이제 알리 직수입 트래픽도 완벽하게 받아낸다. 엔진 예외 처리 1승 적립.</p>
<hr />
<h2 id="🔥-scene-3--엔드포인트-미스매치-디버그-포그-해제">🔥 Scene 3 : 엔드포인트 미스매치 (디버그 포그 해제)</h2>
<p>연도 버그를 픽스했는데도 상태 필드가 묘하게 비어 나왔다.
웹사이트 디버그 창(F12)을 켜서 네트워크 트래픽을 스니핑 해보니, 내가 구글링해서 주워 온 <code>iatrpt/expentp/extractList</code> 라는 엔드포인트는 비공식 야매 루트였고, 찐 공식 엔드포인트는 <code>cargCsclPrgsInfoQry/retrieveCargCsclPrgsInfo</code> 였다.</p>
<p>&quot;아잇 싯팔, 공식 문서 좀 제대로 읽을걸!&quot;</p>
<p>엔드포인트 URL을 교체하고, <code>stderr</code> 에만 뜨게 몰래 디버그 로그 파이프라인을 뚫어서 실제 JSON 프로퍼티 트리를 싹 다 덤프 떴다.
적출국은 <code>shipNatNm</code>, 적재항은 <code>ldprNm</code>, 화물구분은 <code>cargTp</code>... 
뇌피셜로 때려 맞췄던 클래스 필드명 매핑을 실제 API 명세와 일치시키는 대공사를 진행했다. </p>
<hr />
<h2 id="🎨-scene-4--마크다운-ui-모딩-너무-똑똑한-클라이언트의-부작용">🎨 Scene 4 : 마크다운 UI 모딩 (너무 똑똑한 클라이언트의 부작용)</h2>
<p>데이터 연동이 끝났으니 이제 렌더링 퀄리티를 높일 차례다.
진행상태 스트링 파싱해서 🛬, 🔄, ✅ 같은 이모지를 박아 넣었고, &quot;20260309100521&quot; 같은 못생긴 타임스탬프 스파게티를 &quot;03월 09일 (월) 10:05&quot; 같은 휴먼-리더블 UI 프레임워크로 싹 포맷팅 해줬다. 통관 이력도 최신순으로 정렬 완료!</p>
<p><strong>그런데, AI 클라이언트 녀석이 자꾸 내 화려한 UI를 파괴한다.</strong>
서버에서 아무리 이쁘게 풀사이즈 마크다운을 뿌려줘도, Claude 엔진이 &quot;오 님 통관 완료됐네용 축하축하~&quot; 하면서 자기 맘대로 세 줄 요약을 해버리는 참사가 발생한 것.</p>
<p>&quot;야이 눈치없는 자식아 내가 짠 렌더링 파이프라인 무시하지 말라고!!&quot;</p>
<p>결국 MCP Tool Description(도구 설명서)의 시스템 프롬프트에 샷건을 쳤다.</p>
<blockquote>
<p>*&quot;반환된 결과는 절대로 요약하지 말고, 마크다운 형식 그대로 사용자에게 표시할 것. (경고함 진짜)&quot;*</p>
</blockquote>
<p>이후 완전히 굴복한 클라이언트가 내가 의도한 템플릿 100% 원형 그대로 출력하게 만드는 데 성공했다. UI/UX 장인 타이틀 획득 완료. </p>

<h2 id="🚀-final-boss--npm-배포와-npx의-마법">🚀 Final Boss : NPM 배포와 npx의 마법</h2>
<p>이번 메인스트림의 최종 목표 역시 글로벌 퍼블리싱.
이제 <code>npm list -g</code> 치면서 글로벌 오염도 걱정할 필요 없이, 어디서나 클라우드 스트리밍 땡기듯 한 줄 커맨드로 실행해야 한다.</p>
<p><code>package.json</code>에서 <code>&quot;files&quot;: [&quot;dist&quot;, &quot;README.md&quot;, &quot;LICENSE&quot;]</code> 로 불필요한 에셋은 다 다이어트 시키고, 퍼블리시 전 훅으로 <code>prepublishOnly</code> 컴파일 파이프라인을 태웠다. </p>
<p>그리고 README 파일 대문짝에 박아넣은 영광스러운 커맨드:</p>
<pre><code class="language-json">&quot;command&quot;: &quot;npx&quot;,
&quot;args&quot;: [&quot;-y&quot;, &quot;korea-unipass-mcp&quot;]</code></pre>
<p>이제 개발 환경 타겟팅 없이 누구나 <code>npx</code> 하나면 1초 컷으로 내 관세청 서버를 로딩할 수 있다. </p>
<p>GitHub에 Release v1.0.0 태그 쾅 찍어주고, 한글/영문을 섞어 멋지게 릴리즈 노트를 배포했다.</p>
