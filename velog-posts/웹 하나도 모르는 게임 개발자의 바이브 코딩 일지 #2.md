<h2 id="🎮-prologue--phase-1--2는-그저-튜토리얼이었다">🎮 Prologue : Phase 1 &amp; 2는 그저 튜토리얼이었다</h2>
<p>지난 편에서 CRT 효과, 부팅 시퀀스, 인증 로직까지 구현했다. &quot;오오, 폴아웃 느낌 난다!&quot; 하고 흥분했는데... 그건 그냥 튜토리얼이었다.</p>
<p>이제 진짜가 시작된다. <strong>탭 구조 확장, Admin 로그인, 그리고 CSS flexbox와의 또 다른 전쟁.</strong></p>

<h2 id="⚔️-scene-1--data는-너무-심심하다-quests로-리브랜딩">⚔️ Scene 1 : DATA는 너무 심심하다 (QUESTS로 리브랜딩)</h2>
<p>기존 DATA 탭을 보니 너무 밋밋했다. 그냥 프로젝트 목록만 덩그러니 있고, 뭐가 진행 중인지 완료된 건지 한눈에 안 들어온다.</p>
<p><strong>&quot;AI야, DATA 탭을 QUESTS로 바꾸고 IN PROGRESS / COMPLETED 섹션으로 나눠줘. 진행 중인 프로젝트는 프로그레스 바도 넣고.&quot;</strong></p>
<pre><code class="language-jsx">const inProgressProjects = [
  {
    name: 'WITCHDICE',
    description: '주사위 기반 퍼즐형 로그라이크 게임',
    progress: 10,
    // ...
  },
  {
    name: 'DAILY BREW',
    description: 'A cozy coffee shop simulation game',
    progress: 65,
    // ...
  },
];

const releasedProjects = [
  // 완료된 프로젝트들...

<p>그리고 노란색 프로그레스 바를 추가했다. 녹색 status가 released, 노란색이 in progress.</p>
<pre><code class="language-css">.progress-fill {

  box-shadow: 0 0 8px rgba(255, 170, 0, 0.4);
}</code></pre>
<p>이제 &quot;퀘스트 진행 중&quot; 느낌이 산다! RPG 게임에서 퀘스트 로그 보는 것 같다.</p>

<h2 id="🌪️-scene-2--탭-대폭발-logs-inventory-contact-추가">🌪️ Scene 2 : 탭 대폭발 (LOGS, INVENTORY, CONTACT 추가)</h2>
<p>STAT, QUESTS만 있으니 뭔가 부족했다. 내 경력, 대외활동, 연락처는 어디다 넣지?</p>
<p><strong>&quot;AI야, 탭 3개 더 만들어줘. LOGS는 경력 타임라인, INVENTORY는 대외활동, CONTACT는 연락처.&quot;</strong></p>
<h3 id="logs-탭---경력-타임라인">LOGS 탭 - 경력 타임라인</h3>
<pre><code class="language-jsx">const logs = [

      { date: '01', title: 'DAILY BREW 사이드 프로젝트 시작', desc: '카페 시뮬레이션 게임 개발 시작' },

<p>연도별로 왼쪽에 선을 그어서 타임라인 느낌을 냈다. CSS <code>border-left</code>로 간단하게 구현.</p>
<h3 id="inventory-탭---대외활동수상내역">INVENTORY 탭 - 대외활동/수상내역</h3>
<pre><code class="language-jsx">const activities = [

<p>타입별로 다른 색상을 적용했다. <code>GAME JAM</code>은 주황색, <code>EXHIBITION</code>은 보라색... 인벤토리 아이템처럼 각자 다른 희귀도 색상!</p>
<h3 id="contact-탭---연락처">CONTACT 탭 - 연락처</h3>
<p>GitHub, Email, LinkedIn, Blog 링크를 넣었다. 클릭하면 해당 페이지로 이동.</p>
<p>그리고 헤더에 <strong>UPTIME 실시간 시간 표시</strong>도 추가했다.</p>
<pre><code class="language-jsx">useEffect(() =&gt; {

<p>유니티 <code>Update()</code> 루프 같은 느낌? 1초마다 상태를 업데이트한다.</p>

<h2 id="🔥-scene-3--admin의-습격-빨간색-경고-모달">🔥 Scene 3 : Admin의 습격 (빨간색 경고 모달)</h2>
<p>숨겨진 <strong>[ ??? ]</strong> 버튼을 누르면 Admin 로그인 모달이 뜬다. 근데 기존 모달은 녹색이었다. Admin인데 녹색이라니, 위반감이 없다.</p>
<p><strong>&quot;AI야, Admin 모달은 빨간색으로 해줘. 경고 느낌 나게.&quot;</strong></p>
<pre><code class="language-css">.admin-modal {

<h2 id="💀-scene-4--프로젝트-카드-레이아웃-전쟁-flexbox-너란-녀석">💀 Scene 4 : 프로젝트 카드 레이아웃 전쟁 (flexbox... 너란 녀석)</h2>
<h3 id="1차-전투-프로그레스바-하단-고정">1차 전투: 프로그레스바 하단 고정</h3>
<p>IN PROGRESS 프로젝트 카드를 보니, 프로그레스바가 카드 중간에 둥둥 떠 있었다. TECH STACK이 짧으면 프로그레스바가 위로 올라가 버리는 거다.</p>
<p><strong>&quot;AI야, 프로그레스바를 카드 하단에 고정해줘.&quot;</strong></p>
<pre><code class="language-css">.project-card.clickable .project-tech {
  flex: 1; /* TECH STACK 영역이 늘어남 */
}

.project-progress {
  margin-top: auto; /* 프로그레스바를 하단으로 */
}</code></pre>
<p>음... 됐다! 근데 TECH STACK이 너무 늘어나서 밋밋해 보인다.</p>
<h3 id="2차-전투-tech-stack-고정-프로그레스바만-하단으로">2차 전투: TECH STACK 고정, 프로그레스바만 하단으로</h3>
<p><strong>&quot;AI야, TECH STACK은 고정하고 프로그레스바만 하단에 고정해줘.&quot;</strong></p>
<pre><code class="language-css">.project-tech {
  flex-shrink: 0; /* 늘어나지 않음 */
}

.project-progress {
  margin-top: auto; /* 이것만 하단으로 */
}</code></pre>
<p>완벽! 이제 TECH STACK은 내용만큼만 차지하고, 프로그레스바는 항상 하단에 붙어 있다.</p>
<h3 id="3차-전투-completed-quests의--click-for-details-도-하단-고정">3차 전투: COMPLETED QUESTS의 [ CLICK FOR DETAILS ]도 하단 고정</h3>
<p>COMPLETED 섹션은 프로그레스바가 없다. 그래서 [ CLICK FOR DETAILS ] 텍스트가 카드 중간에 떠 있었다.</p>
<p><strong>&quot;이것도 하단에 고정해줘.&quot;</strong></p>
<pre><code class="language-css">.project-click-hint {
  margin-top: auto;
}</code></pre>
<p>이제 모든 카드가 깔끔하게 정렬되었다. CSS flexbox... 너란 녀석, 알고 보면 어렵지 않은데 처음엔 진짜 헷갈린다. 유니티 <code>VerticalLayoutGroup</code> + <code>Content Size Fitter</code> 조합이 그립다...</p>

<p><strong>CSS flexbox, 이제 좀 알 것 같은데?</strong></p>
<p><code>flex: 1</code>, <code>flex-shrink: 0</code>, <code>margin-top: auto</code>... 이 세 개만 알면 레이아웃 끝난다. 유니티 <code>Layout Group</code>이랑 <code>Content Size Fitter</code> 조합하는 거랑 비슷하네.</p>
<p>그리고 <code>display: grid</code>도 써봤다. 프로젝트 카드 그리드.</p>
<pre><code class="language-css">.projects-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 20px;
}</code></pre>
<p>이거 <code>auto-fill</code>이 진짜 편하다. 화면 크기에 따라 자동으로 컬럼 개수 조절해준다. 유니티 <code>GridLayoutGroup</code>이랑 비슷한데, 반응형까지 자동으로 됨.</p>
